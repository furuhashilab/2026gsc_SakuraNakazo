# 東松山市における過去の水害発生地域と現在の洪水ハザードマップの比較分析

## 1. 研究概要
本研究では、埼玉県東松山市を対象に、過去の水害発生地域と現在公表されている洪水ハザードマップを比較し、両者の空間的な関係を分析する。

## 2. 研究目的
過去に水害が発生した地域と、現在の洪水ハザードマップで浸水リスクが示されている地域の分布を比較することで、地域の水害リスクの特徴を明らかにすることを目的とする。

## 3. 分析方法
- 過去の水害発生記録・浸水実績データの収集
- 現在の洪水ハザードマップの取得
- QGISを用いた地理空間データの重ね合わせ
- 過去の水害発生地域と現在の浸水想定区域の比較
- 地域ごとの分布や人口との関係の分析

## 4. 使用予定ツール
- QGIS
- GitHub
- 地理空間データ（GISデータ）

## 8. 研究上の留意点
過去の水害記録と現在の洪水ハザードマップでは、対象期間や作成条件が異なる可能性があるため、データの性質を確認したうえで比較する。
