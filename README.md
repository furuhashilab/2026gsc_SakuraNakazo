# 過去の水害による浸水推定範囲と現在の洪水浸水想定区域の空間的不一致に関する研究

## ― 埼玉県東松山市における浸水区域と高齢人口分布のGIS分析 ―

**青山学院大学 地球社会共生学部**

**研究対象：2019年東日本台風／都幾川流域を中心とする東松山市**

---

# Abstract（概要）

近年、日本では台風や集中豪雨による河川の氾濫が各地で発生しており、地域ごとの水害リスクを把握することが重要となっている。現在、国や自治体によって洪水浸水想定区域を示すハザードマップが公開されており、想定される浸水範囲や浸水深を事前に確認することができる。

一方、過去の水害による浸水推定範囲と現在の洪水浸水想定区域は、必ずしも空間的に一致するとは限らない。両者の違いを把握することは、地域の水害リスクを多角的に理解するうえで重要である。

本研究では、埼玉県東松山市を対象に、2019年東日本台風による浸水推定範囲と現在の洪水浸水想定区域をGISによって重ね合わせ、空間的な一致・不一致を分析する。

さらに、2020年国勢調査の地域メッシュ統計を活用し、過去と現在の浸水区域が重複する地域、過去の浸水推定範囲のみに含まれる地域、現在の浸水想定区域のみに含まれる地域に分類する。それぞれの面積、総人口、65歳以上人口および高齢化率を算出する。

これにより、過去の水害実績と現在の洪水リスク評価の空間的な関係を明らかにするとともに、区域の一致・不一致と地域の人口構成との関係を地理的に考察する。

**キーワード：** 洪水、浸水推定図、ハザードマップ、高齢人口、人口メッシュ、GIS、QGIS、東松山市

---

# I. Introduction（研究背景・目的）

## 1.1 研究背景

近年、日本では台風や集中豪雨による河川の氾濫が各地で発生している。こうした水害に対して、国や自治体では洪水ハザードマップが公開されており、想定される洪水の浸水範囲や浸水深を事前に確認することができる。

国土交通省によると、洪水浸水想定区域は、想定し得る最大規模の降雨などを前提に、河川が氾濫した場合に浸水が想定される区域を示したものである。

このように、過去の災害記録と現在の防災情報は、地域の水害リスクを把握するうえで重要な地理空間情報である。

## 1.2 問題提起

過去の浸水推定範囲と現在の洪水浸水想定区域は、作成時期や想定条件、調査方法が異なる。

そのため、過去に浸水した地域が現在の洪水浸水想定区域にどの程度含まれているのかを、空間的に確認する必要がある。

また、両者が一致しない地域については、区域の違いを確認するだけでは十分ではない。そこにどの程度の人口が居住し、特に高齢者人口がどのように分布しているのかを把握することも重要である。

## 1.3 研究目的・研究課題

本研究では、過去の浸水推定範囲と現在の洪水浸水想定区域の空間的不一致に着目し、その不一致が見られる地域の総人口・65歳以上人口・高齢化率を比較する。

具体的には、以下の3点を明らかにする。

1. 過去の浸水推定範囲と現在の洪水浸水想定区域は、どの程度空間的に一致しているのか。
2. 両者が一致しない地域には、どのような地理的特徴があるのか。
3. 浸水区域の一致・不一致と総人口・高齢人口・高齢化率には、どのような関係があるのか。

本研究の特徴は、過去の浸水状況、現在の浸水想定、地域の人口構成という3種類の地理空間情報を組み合わせて分析する点にある。

なお、既存研究との差別化については、先行研究の全文や関連文献を追加調査したうえで最終的に確定する。

# II. Methods（研究方法）

## 2.1 対象地域

対象地域は、埼玉県東松山市とする。

特に、2019年の東日本台風による浸水被害が発生した都幾川流域を中心に分析する。

過去の浸水推定範囲と現在の洪水浸水想定区域を比較し、地域ごとの空間的な特徴を把握する。

## 2.2 使用データ

| データ | 用途 |
|---|---|
| 2019年東日本台風の浸水推定図・浸水実績データ | 過去の浸水範囲 |
| 現在の洪水浸水想定区域データ | 現在の浸水リスク |
| 2020年国勢調査の地域メッシュ統計 | 総人口・65歳以上人口 |
| 東松山市の行政区域データ | 分析対象地域の抽出 |

※各データの対象年次、提供元、座標系、解像度、作成条件を確認し、取得後に記録する。

## 2.3 GISによる空間分析

QGISを用いて、以下の手順で分析を行う。

### ① データの取得・整備

過去の浸水推定図、現在の洪水浸水想定区域、国勢調査の地域メッシュ統計を取得する。

各データの座標系を統一し、東松山市の行政区域を基準として分析範囲を整理する。

### ② 浸水区域の重ね合わせ

過去の浸水推定範囲をA、現在の洪水浸水想定区域をBとして、GIS上で重ね合わせる。

その結果、以下の3つの区域に分類する。

- **① 重複区域（A ∩ B）：** 過去の浸水推定範囲と現在の浸水想定区域の両方に含まれる地域
- **② 過去のみの区域（A − B）：** 過去の浸水推定範囲に含まれるが、現在の浸水想定区域には含まれない地域
- **③ 現在のみの区域（B − A）：** 現在の浸水想定区域に含まれるが、過去の浸水推定範囲には含まれない地域

### ③ 空間的一致率の算出

過去の浸水推定範囲のうち、現在の洪水浸水想定区域と重なる割合を算出する。

**過去の浸水推定範囲を基準とした一致率**

(A ∩ B) / A × 100

また、現在の洪水浸水想定区域のうち、過去の浸水推定範囲と重なる割合も算出する。

**現在の洪水浸水想定区域を基準とした一致率**

(A ∩ B) / B × 100

この2つの割合を区別することで、過去の浸水推定範囲が現在の想定区域にどの程度含まれているか、逆に現在の想定区域のどの程度が過去の浸水推定範囲と重なるかを把握する。

### ④ 人口統計との重ね合わせ

2020年国勢調査の地域メッシュ統計を活用し、各区域に含まれる総人口と65歳以上人口を集計する。

さらに、65歳以上人口を総人口で除して高齢化率を算出する。

**高齢化率**

65歳以上人口 / 総人口 × 100

これにより、浸水区域の一致・不一致と地域の人口構成との関係を比較する。

※メッシュの面積按分や境界をまたぐ人口の取り扱いについては、分析時に統一した集計方法を設定する。

### ⑤ 地図の作成・結果の可視化

QGISを用いて、以下の分析図を作成する。

- 過去の浸水推定範囲図
- 現在の洪水浸水想定区域図
- 過去と現在の浸水区域の比較図
- 高齢人口分布と浸水区域の重ね合わせ図

# III. Expected Results（期待される成果）

本研究では、以下の成果を目指す。

1. 過去の浸水推定範囲と現在の洪水浸水想定区域の空間的一致率の把握
2. 両区域の重複部分および非重複部分の地理的特徴の可視化
3. 各区域における総人口・65歳以上人口・高齢化率の比較
4. 浸水区域の空間的不一致と地域の人口構成との関係の把握

これらの分析を通じて、過去の水害実績と現在の洪水リスク評価を組み合わせた地域防災の検討に役立つ基礎資料を作成する。

---

# IV. Limitations（研究上の留意点）

過去の浸水推定範囲と現在の洪水浸水想定区域は、作成時期、対象降雨、河川、推定方法などが異なる可能性がある。

そのため、単純な空間的不一致をもって、現在のハザードマップの精度や危険性を直接評価することはできない。

また、過去の浸水推定範囲は、実際の浸水状況を完全に再現したものとは限らないため、データの作成条件を確認する必要がある。

さらに、人口メッシュ統計は地域単位の人口分布を示すものであり、個人ごとの避難能力や実際の被災可能性を直接示すものではない。

これらの限界を踏まえ、データの性質を明確にしたうえで分析・考察を行う。

---

# V. Conclusion（結論・研究の意義）

本研究では、埼玉県東松山市を対象に、2019年の東日本台風による浸水推定範囲と現在の洪水浸水想定区域の空間的な関係を分析する。

さらに、2020年国勢調査の地域メッシュ統計を活用し、両者の重複地域および不一致地域における総人口と65歳以上人口の分布を比較する。

これにより、過去の水害実績と現在の洪水リスク評価の空間的な違いを明らかにするとともに、地域ごとの人口構成との関係を把握する。

また、地理空間情報と人口統計を組み合わせた分析を通じて、地域の水害リスクを複数の視点から捉えることの重要性を示す。
