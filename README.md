# 初心者ダイバーのためのダイビングポイント推薦Webアプリケーションの開発と利便性の検証

本研究は卒論時まで継続的に行う研究として、最終的にはWebアプリケーションの完成を目標とする。

---

# 概要（Abstract）

## 対象テーマ

初心者ダイバーのためのダイビングポイント推薦Webアプリケーションの開発と利便性の検証

## 方針

本研究は、初心者ダイバーが安心してダイビングポイントを選択できる環境を提供することを目的とし、全国のダイビングポイント情報を地図上に集約したWebアプリケーションを開発する。研究は「プロトタイプの実装」「ユーザビリティ評価」「データ分析」の3段階で進め、利便性の向上を検証する。

## 主要な動き

ダイビングポイントを地図上で可視化し、

- ライセンスレベル
- 水深
- 流れの強さ
- 見られる生物
- ベストシーズン
- アクセス方法
- ダイビングショップ

などの情報を一元化したWebアプリケーションを制作する。

## アプローチ

Webアプリケーションの開発に加え、実際のダイバーを対象としたアンケートや操作テストを実施し、検索のしやすさや利用満足度を評価する。

---

# 導入（Introduction）

近年、スキューバダイビングは幅広い世代に親しまれているが、初心者にとっては「自分のレベルに合ったポイント」を探すことが難しい。

現在、ダイビングポイントの情報はショップごとのホームページやSNSなど複数の媒体に分散しており、

- 初心者向けか
- 見られる生物
- 水深
- アクセス方法

などを一度に比較することは容易ではない。

そこで本研究では、ダイビングポイント情報を地図上に集約し、初心者でも目的に応じて簡単に検索・比較できるWebアプリケーションを開発する。

---

# 今後の研究目標（Milestones）

## ① ダイビングポイント情報の一元化

全国のダイビングポイントについて、

- ライセンスレベル
- 水深
- エントリー方法
- ベストシーズン
- 見られる海洋生物
- アクセス方法

などの情報を収集し、地図上で閲覧できるデータベースを構築する。

## ② 誰でも使いやすいWebアプリの開発

利用者が

- 初心者向け
- ウミガメが見たい
- ボートダイビング
- ビーチダイビング

などの条件から検索できるWebアプリケーションを開発する。

## ③ 利便性の検証

完成したWebアプリを実際のダイバーやダイビング経験者に利用してもらい、

- 情報を探しやすくなったか
- 行きたいポイントが見つけやすくなったか
- 初心者でも使いやすいと感じたか

についてアンケートを実施し、アプリの有効性を検証する。

# 予想される課題

## 課題1：情報の更新

ダイビングポイントやショップ情報は変更されることがあるため、継続的なデータ更新が必要である。

### 対策

利用者から情報を投稿できる仕組みを検討する。

## 課題2：利用者の確保

ユーザビリティ評価のための被験者を十分に集める必要がある。

### 対策

大学のダイビングサークルや知人のダイバーに協力を依頼する。
