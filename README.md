# 過去の水害による浸水推定範囲と現在の洪水浸水想定区域の空間的不一致に関する研究

## ― 埼玉県東松山市における浸水区域と高齢人口分布のGIS分析 ―

**青山学院大学 地球社会共生学部**

**研究対象：2019年東日本台風／都幾川流域を中心とする東松山市**

---

# Abstract（概要）

近年、日本では台風や集中豪雨による河川の氾濫が繰り返し発生しており、住宅地や交通網、地域の生活基盤に大きな被害をもたらしている。こうした水害を事前に把握するため、各自治体では洪水浸水想定区域を示したハザードマップが公開されている。

しかし、過去に実際に浸水したと推定される地域と、現在の洪水浸水想定区域がどの程度一致しているのか、また、その一致・不一致が見られる地域にどのような人口構成が存在するのかを、地域単位で把握することは重要である。

本研究では、2019年の東日本台風によって浸水被害が発生した埼玉県東松山市の都幾川流域を中心に、国土地理院が公開する浸水推定図と現在利用可能な洪水浸水想定区域の地理空間データをGISによって比較する。

さらに、2020年国勢調査の地域メッシュ統計を活用し、過去と現在の浸水区域が重複する地域、過去の浸水推定範囲のみに含まれる地域、現在の浸水想定区域のみに含まれる地域に分類する。それぞれの面積、総人口、65歳以上人口および高齢化率を算出する。

これにより、過去の水害実績と現在の洪水リスク評価の空間的な関係を明らかにするとともに、区域の一致・不一致と地域の人口構成との関係を地理的に考察する。

**キーワード：** 洪水、浸水推定図、ハザードマップ、高齢人口、人口メッシュ、GIS、QGIS、東松山市

---

# I. Introduction（研究背景・目的）

## 1.1 研究背景

日本では、台風や集中豪雨による河川の氾濫が繰り返し発生しており、住宅地や交通網、地域の生活基盤に大きな被害をもたらしている。

2019年10月の令和元年東日本台風では、埼玉県東松山市を流れる都幾川や越辺川などで堤防決壊が発生し、広範囲で浸水被害が生じた。東松山市の資料にも、当時の浸水状況が記録されている。

一方、現在では洪水浸水想定区域図やハザードマップが公開されており、想定される洪水の浸水範囲や浸水深を事前に確認することができる。

国土交通省によると、洪水浸水想定区域は、想定し得る最大規模の降雨などを前提に、河川が氾濫した場合に浸水が想定される区域を示したものである。

このように、過去の災害記録と現在の防災情報は、地域の水害リスクを把握するうえで重要な地理空間情報である。

## 1.2 問題提起

過去の浸水推定範囲と現在の洪水浸水想定区域は、作成時期や想定条件、調査方法が異なる。

そのため、過去に浸水した地域が現在の洪水浸水想定区域にどの程度含まれているのかを、空間的に確認する必要がある。

また、両者が一致しない地域については、区域の違いを確認するだけでは十分ではない。そこにどの程度の人口が居住し、特に高齢者人口がどのように分布しているのかを把握することも重要である。

したがって、過去の浸水推定範囲と現在の浸水想定区域を比較するとともに、人口構成を組み合わせた分析が必要である。

## 1.3 先行研究

本研究では、主に以下の研究・資料を参考にする。

### ① 都幾川流域における2019年東日本台風の浸水被害に関する研究

青山雅史による「2019年台風19号による都幾川流域浸水域の土地条件と治水対策」では、2019年の浸水状況、地形条件、ハザードマップとの関係、過去の浸水履歴、河川整備の歴史的経緯などが検討されている。

同研究では、現地調査や空中写真の判読、GISを用いた地形条件と浸水範囲の比較が行われている。

本研究では、この研究を踏まえ、過去の浸水推定範囲と現在の浸水想定区域の空間的な一致・不一致に着目し、さらに人口構成の観点から分析する。

参考：J-STAGE

### ② 洪水災害時の被災人口に関する研究

国勢調査の細かな地域メッシュを利用して、洪水災害時の被災人口を推定する研究も行われている。

例えば、群馬県前橋市を対象とした研究では、125mメッシュの人口情報と洪水ハザードマップをGIS上で重ね合わせ、浸水深別の人口や高齢者人口の分布を分析している。

本研究では、人口メッシュを利用する分析手法を参考にしながら、過去の浸水推定範囲と現在の浸水想定区域の不一致に焦点を当てる。

参考：J-GLOBAL

### ③ 国土地理院による浸水推定図

国土地理院は、2019年の東日本台風について、荒川水系の入間川・越辺川・都幾川の浸水推定図を公開している。

浸水範囲の輪郭線はGeoJSONやシェープファイル形式でも提供されており、GISによる空間分析に利用できる。

参考：国土地理院

## 1.4 研究課題（Research Question）

本研究では、次の問いを設定する。

**RQ：2019年の東日本台風による浸水推定範囲と現在の洪水浸水想定区域は、どの程度空間的に一致しており、両者の一致・不一致が見られる地域では、総人口や65歳以上人口にどのような分布の特徴が見られるのか。**

この問いを、以下の3つの小課題に分けて検証する。

- **RQ1：** 過去の浸水推定範囲と現在の洪水浸水想定区域は、面積・位置の点でどの程度一致しているか。
- **RQ2：** 過去と現在の区域が一致する地域と一致しない地域では、人口分布にどのような違いがあるか。
- **RQ3：** 区域の一致・不一致が見られる地域では、65歳以上人口や高齢化率にどのような特徴があるか。

# II. Methods（研究方法）

## 2.1 対象地域

対象地域は、埼玉県東松山市とする。

特に、2019年の東日本台風による浸水被害が発生した都幾川周辺を重点的に分析する。

東松山市を対象とする理由は、2019年の浸水推定図や自治体の水害ハザードマップ、災害記録などが公開されており、過去の浸水状況と現在の洪水浸水想定区域を比較するための地理空間データをGISによって取得・分析できるためである。

## 2.2 使用データ

| データ | 提供元 | 使用目的 |
|---|---|---|
| 2019年浸水推定図 | 国土地理院 | 過去の浸水範囲 |
| 洪水浸水想定区域等 | 国土交通省・埼玉県 | 現在の想定範囲 |
| 2020年国勢調査メッシュ統計 | 総務省統計局・e-Stat | 総人口・高齢人口 |
| 行政区域データ | 国土数値情報等 | 分析範囲の設定 |
| QGIS | オープンソースGIS | 空間分析・地図作成 |

国勢調査の地域メッシュ統計は、250mメッシュを基本として利用する。e-Statでは国勢調査の地域メッシュデータが提供されている。

また、国土交通省の国土数値情報では、洪水浸水想定区域データのGISでの利用方法や取得手順が紹介されている。

## 2.3 分析項目

本研究では、以下の7項目を分析する。

| 分析項目 | 分析内容 |
|---|---|
| ① 過去の浸水推定範囲 | 2019年の浸水範囲を地図化 |
| ② 現在の浸水想定区域 | 現在の洪水浸水想定区域を地図化 |
| ③ 空間的な重複 | 両者が重なる範囲を抽出 |
| ④ 空間的な不一致 | 過去のみ・現在のみの範囲を抽出 |
| ⑤ 面積比較 | 各区域の面積を算出 |
| ⑥ 人口分布 | 各区域に含まれる総人口を集計 |
| ⑦ 高齢人口分布 | 65歳以上人口と高齢化率を算出 |

## 2.4 調査手順

1. 国土地理院から2019年の浸水推定図のGISデータを取得する。
2. 国土交通省・埼玉県等から、対象河川の洪水浸水想定区域のGISデータを取得する。
3. それぞれのデータについて、作成・更新時期、想定降雨、対象河川、データ形式を確認する。
4. 2020年国勢調査の250mメッシュ統計から総人口・65歳以上人口のデータを取得する。
5. QGIS上で座標系と分析範囲を統一する。
6. 過去の浸水推定範囲と現在の浸水想定区域を重ね合わせる。
7. 両者の重複・不一致を3つの区域に分類する。
8. それぞれの区域の面積を算出する。
9. 人口メッシュを重ね合わせ、区域ごとの総人口・65歳以上人口・高齢化率を算出する。
10. 分析結果を地図・表・グラフに整理する。

## 2.5 分析方法

過去の浸水推定範囲をA、現在の洪水浸水想定区域をBとする。

### ① 空間的な重複・不一致の分類

空間分析では、次の3つの区域に分類する。

**① 重複地域（A ∩ B）**

過去の浸水推定範囲と現在の浸水想定区域の両方に含まれる地域。

**② 過去のみの地域（A − B）**

過去の浸水推定範囲には含まれるが、現在の浸水想定区域には含まれない地域。

**③ 現在のみの地域（B − A）**

現在の浸水想定区域には含まれるが、過去の浸水推定範囲には含まれない地域。

※色はGIS分析図の作成イメージとし、実際の地図作成時に凡例を統一する。

### ② 空間的な一致率

過去の浸水推定範囲のうち、現在の洪水浸水想定区域と重なる割合を算出する。

**過去の浸水推定範囲を基準とした一致率**

(A ∩ B) / A × 100

また、現在の洪水浸水想定区域のうち、過去の浸水推定範囲と重なる割合も算出する。

**現在の洪水浸水想定区域を基準とした一致率**

(A ∩ B) / B × 100

この2つの割合を区別することで、過去の浸水推定範囲が現在の想定区域にどの程度含まれているか、逆に現在の想定区域のどの程度が過去の浸水推定範囲と重なるかを把握する。

### ③ 面積の比較

重複地域、過去のみの地域、現在のみの地域について、それぞれの面積を算出する。

これにより、過去と現在の浸水区域の空間的な違いを定量的に把握する。

### ④ 人口分布の分析

2020年国勢調査の250m人口メッシュを使用し、各区域に含まれる総人口を集計する。

### ⑤ 高齢人口の分析

各区域における65歳以上人口や高齢化率を比較することで、区域の一致・不一致と人口構成の関係を考察する。

**高齢化率の計算式**

65歳以上人口 / 総人口 × 100

これにより、区域の一致・不一致だけでなく、各区域における高齢人口の分布の特徴を比較する。

# IV. Discussion（考察）

## 4.1 過去の浸水推定範囲と現在の浸水想定区域の関係

過去の浸水推定範囲の一部は、現在の洪水浸水想定区域にも含まれると予想される。

一方、両者が一致しない地域も存在する可能性がある。

その違いについて、河川の違い、洪水の発生条件、浸水推定図の作成方法、治水施設の整備状況などを踏まえて考察する。

ただし、区域の不一致のみから治水対策の効果や現在の安全性を判断することはできない。

## 4.2 不一致地域における人口分布の特徴

過去のみの地域と現在のみの地域では、人口分布に違いが見られる可能性がある。

例えば、住宅地と農地では、同じ面積でも居住人口が異なる。

そのため、浸水区域の面積だけではなく、そこに居住する人口を把握することが重要である。

## 4.3 高齢人口の分布と地域特性

各区域における65歳以上人口や高齢化率を比較することで、区域の一致・不一致と人口構成の関係を考察する。

高齢人口の割合が高い地域では、避難支援や情報提供を検討する際に、地域の年齢構成を踏まえる必要がある。

本研究では、こうした地域ごとの人口構成を可視化し、防災上の基礎資料としての活用可能性を検討する。

## 4.4 研究の限界

本研究には、以下の制約がある。

- 国土地理院の浸水推定図は、実際の浸水範囲を完全に把握したものではない。
- 現在の洪水浸水想定区域は想定降雨などの条件に基づくもので、2019年の実際の洪水条件とは異なる。
- 人口メッシュは250m単位であり、個々の建物や住民の位置を正確に示すものではない。
- 人口データは2020年時点であり、分析時点の人口とは異なる。
- 高齢人口の割合だけで、個人の避難能力や支援の必要性を判断することはできない。

そのため、本研究では洪水の発生予測やハザードマップの正確性の判定を目的とせず、公開データを用いた区域の空間的比較と人口構成の分析を目的とする。

# V. Conclusion（結論・研究の意義）

本研究では、埼玉県東松山市を対象に、2019年の東日本台風による浸水推定範囲と現在の洪水浸水想定区域の空間的な関係を分析する。

さらに、2020年国勢調査の地域メッシュ統計を活用し、両者の重複地域および不一致地域における総人口と65歳以上人口の分布を比較する。

これにより、過去の水害実績と現在の洪水リスク評価の空間的な違いを明らかにするとともに、地域ごとの人口構成との関係を把握する。

また、地理空間情報と人口統計を組み合わせた分析を通じて、地域の水害リスクを複数の視点から捉えることの重要性を示す。
